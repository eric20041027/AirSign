# MakeUC 2026 archive

The working documents from MakeUC 2026 (2026-11-07 and 2026-11-08), where AirSign was built in about 18 hours. They are kept as a record of how the project was designed, tested and presented, and are not maintained. Testers are referred to by code name (Tester A, B, C, or A, B, C in the Chinese documents). For the current project, start at the [README](../../README.md).
