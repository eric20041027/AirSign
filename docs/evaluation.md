# AirSign evaluation

Waiting for the test-mode records from [docs/test-protocol.md](test-protocol.md). After each session, this file
and the two charts in `docs/evaluation/` are regenerated by:

```bash
cd tools/tuning
python tune.py --test-logs C:/airsign-data/mac1-S1 C:/airsign-data/mac2-S1 --report ../../docs/evaluation.md
```

The report will have:

- Acceptance per scenario (A1 owner per session, A2–A4 imitators, A5 gate 1).
- The tightest thresholdFactor (1.0–2.0) that keeps every owner/session at ≥ 95%, for `FeatureScale.rotation` 3 and 1.5.
- 95% upper bounds: the rule of three when no imitation got through.
- The equal error rate.
- Two charts: score distributions by scenario, and acceptance vs thresholdFactor.

The recordings stay outside the repo.
