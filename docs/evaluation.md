# AirSign evaluation

Waiting for the test-mode records from [test-protocol.md](test-protocol.md) (protocol v2). After each session,
this file and the two charts in `docs/evaluation/` are regenerated by:

```bash
cd tools/tuning
python tune.py --test-logs C:/airsign-data/mac1-S1 C:/airsign-data/mac2-S1 --report ../../docs/evaluation.md
```

What it will report:

- **Primary:** the frozen baseline (the app today, thresholdFactor 1.25).
- Every attempt, S2 and S3 included, scored against the owner's S1 templates.
- k/n per owner and scenario, with Wilson 95% intervals. A2 as the false accept rate; A3 and A4 as attack
  success rates (ISO/IEC 30107-3 style). EER for S1 only.
- **Secondary:** a factor chosen from S1 owner attempts only (smallest with ≥ 95% accepted, plus 0.10),
  applied unchanged to S2/S3.
- Two charts: scores by scenario, and acceptance vs thresholdFactor.

Disclosure: C (teammate) is both an imitator in these tests and the person writing this analysis.
The recordings stay outside the repo.
