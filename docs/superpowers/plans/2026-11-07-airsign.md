# AirSign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS app that locks any file into an encrypted `.airsign` file from Finder's right-click menu and unlocks it only after the owner signs in the air with their enrolled AirPod (or enters a recovery code).

**Architecture:** One Swift package with two targets. `AirSignCore` is a pure library holding everything testable without hardware: the signature recorder, features, DTW matcher, recovery code, the `.airsign` file format and crypto, file locking, lockout and the encrypted profile store. `AirSign` is a SwiftUI app (an SPM executable wrapped into a signed `.app` by a script). It holds the hardware and OS glue: CoreMotion headphone motion, the CoreAudio device UID, Keychain, windows, the Finder Services menu and file-open handling.

**Tech Stack:** Swift 6.3 toolchain (Xcode 26.5) in Swift 5 language mode, SwiftPM, Swift Testing, SwiftUI/AppKit, CoreMotion (`CMHeadphoneMotionManager`), CoreAudio, CryptoKit (AES-GCM, HKDF, HPKE), Security (Keychain). No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-07-airsign-design.md`

## Global Constraints

- macOS 14+ (`.macOS(.v14)`). Both MacBook Pro (macOS 26.5) and MacBook Air M1 must run it.
- Deadline 2026-11-08 12:00 ET. Built from scratch during the event; the spike is reference only.
- No network calls at all; every byte stays on the Mac.
- Bundle id `com.makeuc.airsign`, app name `AirSign`, locked-file extension `.airsign`, UTI `com.makeuc.airsign.locked`.
- Gate 1 is hard: same AirPods device (CoreAudio output UID) and the same bud side as at enrollment. Gates 2–4 are one total DTW score; per-gate lights are diagnostics only.
- Enrollment = 3 signatures. Lockout: 5 consecutive failures → 5 minutes. Wrong recovery codes count as failures. Discarded attempts (finger slipped, bud switched, too short) do not count.
- Lock needs no signature; unlock needs signature or recovery code.
- Lock writes and verifies the `.airsign` before moving the original to the Trash (never a hard delete). Unlock restores the original and moves the `.airsign` to the Trash.
- The recovery code is shown once and never stored on the Mac.
- Demo mode on: show trace, score, threshold, gate lights, failure reason. Off: show only "Recognized" or "Not recognized".
- Signature data is biometric-like: `spikes/airpods-motion/sessions/`, recordings and the profile never go into git.

## Review Focus

1. Unlocking when a file with the original name already exists in the folder: never overwrite. Restore as `name (unlocked).ext`, then `name (unlocked 2).ext`. Pinned in Task 5.
2. Unsupported input to Lock (an `.airsign` file, a folder, a file over 500 MB, an unreadable file): refuse with a message and change nothing. Pinned in Task 5.
3. A write failure mid-lock (read-only folder, disk full): the original stays untouched and no partial `.airsign` is left behind. Pinned in Task 5.
4. A recovery code typed in lowercase, with spaces, without dashes, or with O/I/L for 0/1/1: still accepted. Pinned in Task 4.
5. AirPods switching bud, disconnecting, or never sending data during a signature: the attempt is discarded with a reason and the lockout count is unchanged. Pinned in Tasks 2 and 6.

### Task 3: Features, DTW and matcher (gate 1 hard, total score decides, gate lights)

**Files:**
- Create: `Sources/AirSignCore/Signature.swift`, `Sources/AirSignCore/DTW.swift`, `Sources/AirSignCore/Matcher.swift`, `Tests/AirSignCoreTests/MatcherTests.swift`, `Tests/AirSignCoreTests/MatcherReplayTests.swift`

**Interfaces:**
- Consumes: `MotionSample`, `BudSide` (Task 2)
- Produces:
  - `public struct Signature: Codable, Equatable { features: [[Double]]; duration: Double; side: BudSide; path: [SIMD3<Double>]; init(samples: [MotionSample]) }`
    - Each feature row is `[rot/3, rot/3, rot/3, acc/0.5, acc/0.5, acc/0.5, grav.x, grav.y, grav.z]`.
    - `path` is the gyro integrated over time.
  - `public func dtwDistance(_ a: [[Double]], _ b: [[Double]], band: Double = 0.25) -> Double`
  - `public enum Gate: String, Codable, CaseIterable { case grip, sizeTempo, rhythm }`
    - `grip` uses the grav columns 6–8.
    - `sizeTempo` uses the acc columns 3–5 with the duration factor.
    - `rhythm` uses the rot columns 0–2.
  - `public struct Enrollment: Codable, Equatable { templates: [Signature]; side: BudSide; deviceUID: String?; threshold: Double; gateThresholds: [Gate: Double] }`
  - `public enum MatcherConfig { static let durationWeight = 0.5; static let thresholdFactor = 1.25; static let enrollCount = 3 }`
  - `public func distance(_ a: Signature, _ b: Signature, columns: Range<Int> = 0..<9, useDuration: Bool = true) -> Double`
    - Result: `dtw × (1 + 0.5·|ln(a.duration / b.duration)|)`, or plain `dtw` when `useDuration` is false.
  - `public enum MatcherError: Error, Equatable { case needAtLeast(Int), mixedSides }`
  - `public func enroll(_ sigs: [Signature], deviceUID: String?) throws -> Enrollment`
    - Throws `MatcherError.needAtLeast(3)` or `.mixedSides`.
    - `threshold` = 1.25 × the largest pairwise distance.
    - Each gate threshold = 1.25 × the largest pairwise distance for that gate.
  - `public struct GateLight: Equatable { gate: Gate; ratio: Double }` (gate score ÷ gate threshold)
  - `public enum Rejection: Equatable { case wrongBud, wrongDevice, scoreTooHigh }`
  - `public struct Verdict: Equatable { accepted: Bool; score: Double; threshold: Double; rejection: Rejection?; lights: [GateLight] }`
  - `public func verify(_ sig: Signature, deviceUID: String?, against e: Enrollment, threshold override: Double? = nil) -> Verdict`
    - `score` = the minimum `distance` to any template.
    - Gate 1 is checked first: `sig.side != e.side` gives `wrongBud`. If both UIDs are non-nil and differ, the result is `wrongDevice`.

`thresholdFactor` 1.25 is my call from spike round 2. The worst enrolled pair there was 0.455, and 0.54 (about 1.2×) separated owner 10/10 from imitators 14/15. Default factor 2 let 12/15 imitators through.

`dtwDistance` (same as the spike):
- Banded around `round(i·m/n)` with half-width `ceil(band·max(n,m))`.
- Frame cost is Euclidean distance over the given columns.
- Result is the total cost ÷ (n+m), or `.infinity` when the band disconnects.

Lights:
- One per gate, computed against all templates (minimum).
- Order `[.grip, .sizeTempo, .rhythm]`.
- Each ratio = gate score ÷ `max(gateThresholds[gate], 1e-6)`. A gate whose enrolled signatures are identical (threshold 0) must not produce NaN.

### Task 4: Recovery code and the `.airsign` file format

**Files:**
- Create: `Sources/AirSignCore/RecoveryCode.swift`, `Sources/AirSignCore/LockedFile.swift`, `Tests/AirSignCoreTests/LockedFileTests.swift`

**Interfaces:**
- Produces:
  - `public enum RecoveryCode`
    - `static func generate() -> String`: 32 Crockford base32 characters (160 random bits), grouped `XXXX-XXXX-…` (8 groups)
    - `static func normalize(_ input: String) throws -> String`: uppercase; strip spaces and dashes; O→0, I/L→1; must be 32 valid characters, otherwise `LockedFileError.badRecoveryCode`
    - `static func privateKey(for code: String) throws -> Curve25519.KeyAgreement.PrivateKey`: HKDF-SHA256 over the decoded 20 bytes, salt `"airsign-recovery-v1"`, 32 bytes
  - `public struct LockedFileHeader: Codable { version: Int = 1; originalName: String; createdAt: Date; masterWrapped: Data; recoveryEncapsulated: Data; recoveryWrapped: Data }`
  - `public enum LockedFile`
    - `static let magic = Data("AIRSIGN1".utf8)`
    - `static func seal(_ plaintext: Data, originalName: String, masterKey: SymmetricKey, recoveryPublicKey: Curve25519.KeyAgreement.PublicKey) throws -> Data`
    - `static func open(_ data: Data, masterKey: SymmetricKey) throws -> (name: String, plaintext: Data)`
    - `static func open(_ data: Data, recoveryCode: String) throws -> (name: String, plaintext: Data)`
    - `static func header(of data: Data) throws -> LockedFileHeader`
  - `public enum LockedFileError: Error, Equatable { case notAirSignFile, unsupportedVersion(Int), authenticationFailed, badRecoveryCode }`

File layout: `magic(8) | headerLength UInt32 big-endian | header JSON | AES.GCM combined(nonce‖ciphertext‖tag)`.
- The data key is a random 256-bit `SymmetricKey`.
- The content is sealed with `authenticating:` the header JSON bytes.
- `masterWrapped` = `AES.GCM.seal(dataKey, using: masterKey).combined`.
- `recoveryWrapped` = HPKE (`.Curve25519_SHA256_ChachaPoly`, info `"airsign-file-v1"`) to the recovery public key. `recoveryEncapsulated` holds the encapsulated key.
- Any CryptoKit failure maps to `.authenticationFailed`.

### Task 5: File locker (lock/unlock on disk, verify before trash, safe naming)

**Files:**
- Create: `Sources/AirSignCore/FileLocker.swift`, `Tests/AirSignCoreTests/FileLockerTests.swift`

**Interfaces:**
- Consumes: `LockedFile`, `LockedFileError` (Task 4)
- Produces:
  - `public struct FileLocker`
    - `init(trash: @escaping (URL) throws -> Void = { try FileManager.default.trashItem(at: $0, resultingItemURL: nil) })`
    - `func lock(_ url: URL, masterKey: SymmetricKey, recoveryPublicKey: Curve25519.KeyAgreement.PublicKey) throws -> URL`: returns the `.airsign` URL
    - `func unlock(_ url: URL, open: (Data) throws -> (name: String, plaintext: Data)) throws -> URL`: returns the restored URL
    - `static let maxBytes = 500 * 1024 * 1024`
  - `public enum FileLockerError: Error, Equatable { case alreadyLocked, isDirectory, tooLarge, unreadable, notLocked, writeFailed(String) }`

Lock order:
1. Validate the input.
2. Read the file.
3. Seal it.
4. Write `<name>.airsign` atomically.
5. Read it back and `LockedFile.open(masterKey:)`, then compare SHA-256 with the original.
6. Call `trash(original)`.

On any failure after step 4 began, remove the `.airsign` and rethrow. If the target `<name>.airsign` already exists, use `<name> 2.airsign`.

Unlock: open, then write to `uniqueURL(dir, originalName)`. The first collision becomes `name (unlocked).ext`, then `name (unlocked 2).ext`. Then call `trash(.airsign)`.
