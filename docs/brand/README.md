# AirSign brand files

| File | Use |
|---|---|
| `airsign-wordmark-light-2400.png` / `.svg` | Logo with the name, for light slides, Devpost and the README |
| `airsign-wordmark-dark-2400.png` / `.svg` | The same for dark backgrounds |
| `airsign-mark-light-1024.png` / `.svg` | The key-and-lock mark alone, for light backgrounds |
| `airsign-mark-dark-1024.png` / `.svg` | The mark alone, for dark backgrounds |
| `airsign-app-icon-1024.png` / `.svg` | The macOS app icon (white rounded square). The app uses `airsign/Resources/AppIcon.icns` |

Colours: ink `#111214`, blue `#1a5cff`; the dark versions use ink `#f3f4f6` on `#14161b`.
Fonts in the wordmark: Inter Bold for “Air”, Mr Dafoe for “Sign”. The SVG wordmarks load them from Google Fonts, so use
the PNGs anywhere offline. The key's inside is filled with the background colour, so pick the light or dark file to match.

Each file is centred on its visible shapes with an even margin; the ear tip sits over the key's head and the shackle
over the lock body.
